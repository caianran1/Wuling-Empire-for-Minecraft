# WuLing Empire / 武灵帝国

《我的世界之武灵帝国》改编模组 · Minecraft 1.20.1 / Forge

## 下载

见 [**Releases**](https://github.com/caianran1/Wuling-Empire-for-Minecraft/releases/latest)，下载 jar 放进 `.minecraft/mods/` 即可。

## 环境要求

Minecraft 1.20.1 · Forge 47.x · Java 17

## 玩法概览

**灵珠** —— 击杀怪物直接掉落，捡起即可，品质决定修炼速度。末影龙另留专属尸体，右键取珠。

**开启武灵** —— 生存：手持灵珠右键村民牧师开启，种类随机；创造：用绑定器自选种类。

**操作** —— `Shift+M` 凝聚武灵、`Shift+N` 打开升级面板、`Shift+P` 解散召唤出的僵尸。书武灵凝聚时会先开附魔书界面，自己挑附魔与等级；附魔越稀有、等级越高，消耗的灵力越多。境界越高，凝聚越省灵力（木境界 25，绿宝石境界只要 10）。

**境界** —— 木 → 石 → 黄金 → 玄铁 → 钻石 → 下界合金 → 绿宝石。

**腐肉武灵** —— 稀有的召唤类武灵：凝聚出一队僵尸随从自动攻击敌人，数量随境界增加，钻石境界起随从可以飞行。

**红石装备** —— 9 个武灵红石粉合成红石锭，再按原版形状打成整套护甲与剑斧镐铲。八件共用一个充能池，攻击、挖掘、挨打、飞行都耗能；手持任意一件右键打开充能菜单，把灵珠喂进去（珠子越好充得越多）。充能耗尽时加成失效、飞不起来、攻击与移速下降。穿红石靴子可以像创造那样飞行。强度按「你的境界 +1 档」浮动，封顶绿宝石档。

**建筑系统** —— 你放下的方块如果底下没有支撑，2 秒后会像沙子一样向下坠落；这 2 秒内用粘液球右键那一格可以把它固定住，之后永远不掉。支撑被挖掉时上方悬空的方块也会跟着塌。自然生成的地形与建筑不受影响。

**创造模式物品栏** —— 模组在创造模式的物品栏里有一个独立的「武灵帝国」标签页，全部灵珠、七个境界的凝聚物与红石装备都在里面，不用再翻原版的分类去找。

**绿宝石装备** —— 除了凝聚，也可以在**工作台用绿宝石块**直接打造，成品与凝聚所得完全一致。
